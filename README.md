# ラーメン店めぐりガイド - スマホ専用サイト

提供された5記事の本文を掲載した、GitHub Pages公開用の静的Webサイトです。

## 公開方法

1. このZIPを解凍します。
2. GitHubでリポジトリを作成します（公開サイトにするならPublic推奨）。
3. `index.html`、`style.css`、`articles.js`、`app.js` をリポジトリのルートにアップロードします。
4. リポジトリの `Settings > Pages` から `Deploy from a branch`、`main`、`/(root)` を選択して保存します。
5. デプロイが完了すると `https://ユーザー名.github.io/リポジトリ名/` で閲覧できます。

## コンテンツ更新方法

- 記事の本文・タイトルなどの編集は `articles.js` を編集してください。
- デザイン・配色は `style.css` で変更できます。
- 各記事は `#article/記事ID` で直接開けます。
- 今回掲載している記事は5本です。自動同期機能はありません。

## A8.net広告（組み込み済み）

いただいたA8.net広告コード2件を `index.html` に**設定済み**です。追加でコードを貼る必要はありません。

| 広告位置 | 広告素材 | HTML設定場所 |
| --- | --- | --- |
| トップページの記事一覧で2番目の記事の直後 | 横長468×60バナー | `template#a8-list-template` |
| 各記事の本文を読み終えた直後（関連記事より前） | 正方形250×250バナー | `template#a8-end-template` |

- HTMLの広告リンク・バナーURL・1×1の計測画像は、送っていただいたコードをそのまま保持しています。
- スマホ画面からはみ出さないように、**横長バナーのみ表示幅に収めるCSS**を設定しています。リンク先や計測用URLは変更していません。
- バナーに「PR・広告」を表示し、ページ上部にもアフィリエイト広告を含む旨を表示します。
- 広告バナーはA8.netのサーバーから取得されるため、インターネット接続や広告ブロック設定によって表示されない場合があります。
- 記事一覧を絞り込んで2件未満になった場合、一覧途中の広告は表示されません。
- 後日広告を差し替えるときは `index.html` の2か所の `<template>` 内をA8.netのコード全文で置き換えます。
- 広告のリンクや計測タグを改変しないでください。GitHub Pagesへ公開されるHTMLの広告コードは公開情報になります。

元のライブドアブログの広告タグ、ランキングバナー、計測用スクリプトは移植していません。
